
# LANtern

LANtern: small project for learning Go and monitoring network services.
## Run

Go matching the version specified in `go.mod` is required.

```bash
git clone https://github.com/Kxzrtx/lantern.git
cd lantern
go run ./cmd/lantern
```

## Project goal

LANtern will be developed step by step into a tool for monitoring the availability of devices and services on a network.
